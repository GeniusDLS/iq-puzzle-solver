# 3D-друкована модель гри

Параметричний генератор: **шаблон-фігура** (один шар **5×10** зі з'єднаних
усічених кубиків — заготовка, решту зручно доробити в CAD, напр. Fusion) +
**фігури** з **усічених кубиків** (truncated cubes), з'єднаних шийками. Фігури
розсунуто **однаково в усіх напрямках** і з'єднано шийками; кубик має **пласке
дно** — друкується на FDM набагато краще (без точкового контакту й звисів).
Масштаб кубика 1 см, крок сітки 12.1 мм. Перевірити: `part="demo"`
(шаблон-привид + фігура A на своєму місці).

> Параметри можна крутити **наживо** у браузері: **`3d/params.html`** (повзунки
> розмірів + 3D-прев'ю + експорт STL прямо зі сторінки).

## Готові STL + превʼю (без сервера)

Сервер/API **не потрібні**:

- **Готові файли** вже лежать у `3d/stl/` (`template.stl`, `piece_A.stl` … `piece_J.stl`).
  Перегенерувати: `node gen_stl.js` (чистий Node, без залежностей і без OpenSCAD).
  Меш — Surface Nets по аналітичному SDF, усе виходить замкнене (водонепроникне).
- **3D-превʼю у браузері:** `3d/preview.html` (three.js, WebGL) — обертання, вибір деталі,
  кнопки завантаження STL. Усе будується з даних. Онлайн:
  **https://geniusdls.github.io/iq-puzzle-solver/3d/preview.html**

> `iq_puzzle.scad` (OpenSCAD) лишається для повного контролю/правок параметрів і чистого CSG.

## Як отримати STL (OpenSCAD-варіант)

1. Встановіть **OpenSCAD** (безкоштовно): https://openscad.org
2. Відкрийте `iq_puzzle.scad`.
3. Праворуч (Customizer) або вгорі змініть `part`:
   - `"template"` — шаблон-блок 2×5×10;
   - `"all"` — усі 10 фігур розкладені для друку разом;
   - `"A"`…`"J"` — окрема фігура.
4. **F6** (рендер) → **File → Export → Export as STL**.

Або пакетно через CLI (якщо OpenSCAD у PATH):

```bash
cd 3d && ./export_stl.sh      # створить stl/template.stl та stl/piece_A.stl … piece_J.stl
```

## Параметри (мм)

| параметр | що це | типове |
|---|---|---|
| `ball_d` | сторона кубика | 10 |
| `cham` | фаска на кожному ребрі кубика (усічення) | 2.0 |
| `wall_in` | номінальна перетинка між комірками (задає проміжок) | 1.5 |
| `gap` | припуск на зазор | 0.3 |
| `neck_w` | переріз шийки, що з'єднує сусідні кубики | 4 |
| `pitch` = `vlayer` | крок сітки = `ball_d + 2·gap + wall_in` (однаковий усюди) | 12.1 |

> **Виміряйте крок на реальній грі** і поставте `ball_d` так, щоб `pitch` збігся — друк буде 1:1.

## Поради до друку

- PLA/PETG, шар 0.2 мм. Кубики мають **пласке (восьмикутне) дно** — чудова адгезія,
  друкуються без підпор. Нижні фаски ідуть під 45°, верхні теж — без звисів.
- Фігури друкуються «лежачи» у своїй природній орієнтації: нижня грань на столі,
  верхні кубики стоять на нижніх (повна опора знизу) — підпори не потрібні. Шийки
  (4 мм) — горизонтальні містки між кубиками, друкуються як короткі брижі.
- Кольори: друкуйте кожну фігуру своїм пластиком (A=жовта, B=помаранчева, C=рожева,
  D=червона, E=голуба, F=бірюзова, G=фіолетова, H=синя, I=салатова, J=зелена).

## Фігури — справжні 3D (модель «петлі»)

Кожна фігура — це **дві пласкі грані зі спільним ребром (петля), складені під 90°**:
грань 1 лежить пласко (z=0), грань 2 стоїть; кубик, що проєктується у стоячій грані,
сидить **зверху**. Координати в `iq_puzzle.scad`/`gen_stl.js` задані як `[col, row, layer]`
(layer 0 = низ). Кількість кубиків: A–F = 7, G–J = 6.

Якщо якась фігура вийде не такою, як у наборі — надішліть її схему, виправлю координати.

## Масштаб 1:1

Виміряйте на реальній грі **крок між кульками** і поставте `ball_d` так, щоб `pitch`
(= `ball_d + 2·gap + wall_in`) дорівнював цьому кроку. `vlayer` = `pitch` тримає
проміжки однаковими в усіх напрямках.
