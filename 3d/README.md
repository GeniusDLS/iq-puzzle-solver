# 3D-друкована модель гри

Параметричний генератор у OpenSCAD: **дошка 5×10** з лунками + **фігури** (зрощені кульки).

## Як отримати STL

1. Встановіть **OpenSCAD** (безкоштовно): https://openscad.org
2. Відкрийте `iq_puzzle.scad`.
3. Праворуч (Customizer) або вгорі змініть `part`:
   - `"board"` — дошка;
   - `"all"` — усі 10 фігур розкладені для друку разом;
   - `"A"`…`"J"` — окрема фігура.
4. **F6** (рендер) → **File → Export → Export as STL**.

Або пакетно через CLI (якщо OpenSCAD у PATH):

```bash
cd 3d && ./export_stl.sh      # створить stl/board.stl та stl/piece_A.stl … piece_J.stl
```

## Параметри (мм) — підженіть під свій набір

| параметр | що це | типове |
|---|---|---|
| `pitch` | крок між центрами кульок | 16 |
| `ball_d` | діаметр кульки фігури | 13.5 |
| `socket_d` / `socket_depth` | діаметр / глибина лунки дошки | 14.5 / 4.5 |
| `neck_ratio` | товщина «шийки» між кульками (× ball_d) | 0.60 |
| `vlayer` | вертикальний крок між шарами (для 3D) | 13.5 |
| `bottom_flat` | зріз низу фігур для прилипання до столу | 1.0 |

> **Виміряйте `pitch` і `ball_d` на реальній грі** — тоді друк буде 1:1.

## Поради до друку

- PLA/PETG, шар 0.2 мм. `bottom_flat` дає кожній нижній кульці плаский «п'ятачок» — друкується без підпор. Якщо `bottom_flat=0`, увімкніть підпори/brim.
- `neck_ratio` ~0.6 робить фігури міцними. Менше = тонші шийки (ближче до вигляду гри, але крихкіше).
- Кольори: друкуйте кожну фігуру своїм пластиком (A=жовта, B=помаранчева, C=рожева, D=червона, E=голуба, F=бірюзова, G=фіолетова, H=синя, I=салатова, J=зелена).

## ⚠️ Фігури поки ПЛАСКІ (1 шар)

Дані в `iq_puzzle.scad` — це 5-кулькові сліди (вони складають повне поле), але **ваш фізичний набір — обʼємний**. Щоб надрукувати справжні 3D-фігури, додайте верхні шари: кожна кулька задається як `[col, row, layer]` (layer 0 = низ, 1 = наступний шар, …).

Найпростіше — описати **кожну фігуру по шарах** ось так, і я впишу координати:

```
Жовта (A):
  шар 0 (низ):      шар 1 (верх):
  × × × ×           · · · ·
  · · · ×           · · · ·
```

`×` = є кулька, `·` = нема. Скільки шарів — стільки сіток. Надішліть — і я оновлю `pieces` у `.scad`, після чого фігури стануть точними 3D-моделями вашого набору.
