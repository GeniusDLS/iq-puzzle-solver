# 3D-друкована модель гри

Параметричний генератор у OpenSCAD: **дошка 5×10** з лунками + **фігури** (зрощені кульки).

## Готові STL + превʼю (без сервера)

Сервер/API **не потрібні**:

- **Готові файли** вже лежать у `3d/stl/` (`board.stl`, `piece_A.stl` … `piece_J.stl`).
  Перегенерувати: `node gen_stl.js` (чистий Node, без залежностей і без OpenSCAD).
- **3D-превʼю у браузері:** `3d/preview.html` (three.js, WebGL) — обертання, вибір деталі,
  кнопки завантаження STL. Онлайн: **https://geniusdls.github.io/iq-puzzle-solver/3d/preview.html**
  (на Pages вантажиться й дошка зі STL; локально через `file://` фігури показуються, а дошку
  блокує політика CORS — відкривайте через сайт).

> `iq_puzzle.scad` (OpenSCAD) лишається для повного контролю/правок параметрів і чистого CSG.

## Як отримати STL (OpenSCAD-варіант)

1. Встановіть **OpenSCAD** (безкоштовно): https://openscad.org
2. Відкрийте `iq_puzzle.scad`.
3. Праворуч (Customizer) або вгорі змініть `part`:
   - `"board"` — дошка;
   - `"all"` — усі 10 фігур розкладені для друку разом;
   - `"A"`…`"J"` — окрема фігура.
4. **F6** (рендер) → **File → Export → Export as STL**.

Або пакетно через CLI (якщо OpenSCAD у PATH):

```bash
cd 3d && ./export_stl.sh      # створить stl/board.stl та stl/piece_A.stl … piece_J.stl
```

## Параметри (мм) — підженіть під свій набір

| параметр | що це | типове |
|---|---|---|
| `pitch` | крок між центрами кульок | 16 |
| `ball_d` | діаметр кульки фігури | 13.5 |
| `socket_d` / `socket_depth` | діаметр / глибина лунки дошки | 14.5 / 4.5 |
| `neck_ratio` | товщина «шийки» між кульками (× ball_d) | 0.60 |
| `vlayer` | вертикальний крок між шарами (для 3D) | 13.5 |
| `bottom_flat` | зріз низу фігур для прилипання до столу | 1.0 |

> **Виміряйте `pitch` і `ball_d` на реальній грі** — тоді друк буде 1:1.

## Поради до друку

- PLA/PETG, шар 0.2 мм. `bottom_flat` дає кожній нижній кульці плаский «п'ятачок» — друкується без підпор. Якщо `bottom_flat=0`, увімкніть підпори/brim.
- `neck_ratio` ~0.6 робить фігури міцними. Менше = тонші шийки (ближче до вигляду гри, але крихкіше).
- Кольори: друкуйте кожну фігуру своїм пластиком (A=жовта, B=помаранчева, C=рожева, D=червона, E=голуба, F=бірюзова, G=фіолетова, H=синя, I=салатова, J=зелена).

## Фігури — справжні 3D

Координати в `iq_puzzle.scad` відновлено з **двох ортогональних проєкцій** (граней)
кожної фігури: грань 1 = вид зверху `(col,row)`, грань 2 = вид спереду `(col,layer)`.
Кулька є в точці `(x,y,z)`, якщо `(x,y)` є у виді зверху **і** `(x,z)` є у виді спереду.
Обидві проєкції перевірено — збігаються з вашими гранями. Кількість кульок:
A=7, B–F=8, G,H=6, I,J=7.

Кожна кулька задається як `[col, row, layer]` (layer 0 = низ). Якщо якась фігура
вийде не такою, як у наборі — надішліть її шари схемою (`×`/`·`), і я виправлю
координати.

## Масштаб 1:1

Виміряйте на реальній грі **діаметр кульки** і поставте `ball_d`, а `pitch` і
`vlayer` зробіть рівними йому (кульки в наборі дотикаються). Лунки дошки: `socket_d`
менший за `pitch`, `socket_depth` — наскільки кулька сідає.
