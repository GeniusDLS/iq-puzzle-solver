# 3D-друкована модель гри

Параметричний генератор: **дошка-лоток**, що огортає повний шаблон 5×10 у 2 шари
із зазором 0.4 мм (будь-яка фігура вільно входить зверху, верхній шар виступає на
пів-висоти), + **фігури** з **усічених кубиків** (truncated cubes). Кубик замість
кульки має **пласке дно** — друкується на FDM набагато краще (без точкового контакту
й звисів). Масштаб 1:1 під комірку 10 мм. Перевірити складання: `part="demo"`
(дошка-привид + фігура A всередині).

## Готові STL + превʼю (без сервера)

Сервер/API **не потрібні**:

- **Готові файли** вже лежать у `3d/stl/` (`board.stl`, `piece_A.stl` … `piece_J.stl`).
  Перегенерувати: `node gen_stl.js` (чистий Node, без залежностей і без OpenSCAD).
  Меш — Surface Nets по аналітичному SDF, фігури виходять замкнені (дотичні кубики
  зрощуються), дошка — чистий лоток.
- **3D-превʼю у браузері:** `3d/preview.html` (three.js, WebGL) — обертання, вибір деталі,
  кнопки завантаження STL. Онлайн: **https://geniusdls.github.io/iq-puzzle-solver/3d/preview.html**
  (на Pages вантажиться й дошка зі STL; локально через `file://` фігури показуються, а дошку
  блокує політика CORS — відкривайте через сайт).

> `iq_puzzle.scad` (OpenSCAD) лишається для повного контролю/правок параметрів і чистого CSG.

## Як отримати STL (OpenSCAD-варіант)

1. Встановіть **OpenSCAD** (безкоштовно): https://openscad.org
2. Відкрийте `iq_puzzle.scad`.
3. Праворуч (Customizer) або вгорі змініть `part`:
   - `"board"` — дошка;
   - `"all"` — усі 10 фігур розкладені для друку разом;
   - `"A"`…`"J"` — окрема фігура.
4. **F6** (рендер) → **File → Export → Export as STL**.

Або пакетно через CLI (якщо OpenSCAD у PATH):

```bash
cd 3d && ./export_stl.sh      # створить stl/board.stl та stl/piece_A.stl … piece_J.stl
```

## Параметри (мм)

| параметр | що це | типове |
|---|---|---|
| `ball_d` | сторона кубика-комірки | 10 |
| `pitch` | крок між центрами комірок (== ball_d, кубики дотикаються) | 10 |
| `vlayer` | вертикальний крок між шарами | 10 |
| `cham` | фаска на кожному ребрі кубика (усічення) | 3.0 |
| `gap` | зазор навколо фігур у лотку (вільний хід) | 0.3 |
| `wall` / `floor` | бічні стінки / дно під нижнім шаром | 3 / 3 |
| `push_d` | отвір у дні під кожною коміркою (виштовхнути фігуру) | 5 |

> **Виміряйте крок на реальній грі** і поставте `ball_d` = `pitch` = `vlayer` — друк буде 1:1.

## Поради до друку

- PLA/PETG, шар 0.2 мм. Кубики мають **пласке (восьмикутне) дно** — чудова адгезія,
  друкуються без підпор. Нижні фаски ідуть під 45°, верхні теж — без звисів.
- Фігури друкуються «лежачи» у своїй природній орієнтації: нижня грань на столі,
  верхні кубики стоять на нижніх (повна опора знизу) — підпори не потрібні.
- Кольори: друкуйте кожну фігуру своїм пластиком (A=жовта, B=помаранчева, C=рожева,
  D=червона, E=голуба, F=бірюзова, G=фіолетова, H=синя, I=салатова, J=зелена).

## Фігури — справжні 3D (модель «петлі»)

Кожна фігура — це **дві пласкі грані зі спільним ребром (петля), складені під 90°**:
грань 1 лежить пласко (z=0), грань 2 стоїть; кубик, що проєктується у стоячій грані,
сидить **зверху**. Координати в `iq_puzzle.scad`/`gen_stl.js` задані як `[col, row, layer]`
(layer 0 = низ). Кількість кубиків: A–F = 7, G–J = 6.

Якщо якась фігура вийде не такою, як у наборі — надішліть її схему, виправлю координати.

## Масштаб 1:1

Виміряйте на реальній грі **крок між кульками** і поставте `ball_d` = `pitch` =
`vlayer` рівними йому. Дошка-лоток огортає шаблон із зазором `gap`; верхній шар
виступає на пів-висоти кубика.
